## 核心区分

先区分两个维度：

1. **表达形式**：作者把一句话说成事实、观点、建议、引用还是问题。
2. **真值/可靠性**：这句话是否真实、证据是否可靠、当前是否仍有效。

分析原文时，第一步只能可靠判断表达形式；真值需要原文证据或外部核验。表格中使用“事实性断言 + 核验状态”，不要用一个“事实”标签掩盖两者差异。

## 混合句拆分

### 例 1：评价词包裹事件

> “那些愚蠢的网友又在疯狂地转发一条毫无根据的谣言。”

拆成：

- `网友转发某条信息`：事件断言，需确认主体、时间和来源；
- `这条信息是谣言/毫无根据`：关于信息真实性或证据的二级断言，不能仅因作者这样说就确认；
- `愚蠢`：对人的评价标签；
- `疯狂地`：对行为程度/方式的评价；
- `又`：带有重复发生的时间/频率暗示，也需证据。

### 例 2：描述、推断、建议连续出现

> “天空出现乌云，所以可能要下雨，出门最好带伞。”

拆成：

1. 天空出现乌云：观察性断言；
2. 可能要下雨：基于观察的概率/因果推断；
3. 出门最好带伞：行动建议；
4. 隐含假设：带伞的成本低于淋雨的成本，且下雨概率达到值得行动的程度。

### 例 3：夸张的普遍命题

> “真正优秀的员工都会主动加班。”

拆成：

- `优秀`：未定义的价值标签；
- `员工主动加班`：行为断言；
- `都会`：全称量词，扩大了范围；
- `优秀与主动加班之间存在必然关系`：因果/规范性假设。

不能把这句话当作一个简单事实；应标为价值判断或弱论证观点，并提示“优秀”的定义和统计证据缺失。

## 证据与论证

按原文实际出现的内容标记证据类型：

| 类型 | 可支持什么 | 常见风险 |
| --- | --- | --- |
| 原始数据/研究 | 数量、趋势、相关或实验结论 | 样本、方法和时效性不明 |
| 原始来源/一手记录 | 事件经过、原话、制度 | 来源选择或上下文缺失 |
| 专家/权威意见 | 专业判断或解释 | 权威不等于证据，可能超出专业范围 |
| 当事人证言 | 亲历信息 | 记忆、利益和观察范围有限 |
| 个人经历 | 个案和体验 | 容易以偏概全 |
| 典型案例/故事 | 帮助理解、吸引注意 | 感染力不等于代表性 |
| 类比/比喻 | 说明结构或直觉 | 相似处可能不构成因果证据 |
| 无依据断言 | 只有结论或情绪 | 需要补充证据和论证 |

“支持强度”只回答：给定原文中的材料，结论被支撑到什么程度？如果没有查外部资料，不能回答世界上是否真的如此。

## 常见误判

| 误判 | 修正 |
| --- | --- |
| 名词+动词就是事实 | 先问动作是否可观察、主体和范围是否明确；“骗子”“欺骗”也带评价或指控 |
| 形容词+副词就是观点 | 有些是可测描述；“3米高”“每周两次”要保留为描述并检查来源 |
| 有数字就是事实 | 数字可能被断章取义，仍需来源、口径、时间和计算方式 |
| 引用了专家就是已证实 | 记录“专家意见”，再评价是否有研究或原始数据支持 |
| 观点没有真假所以无需论证 | 对观点评价论据、推理有效性、适用边界和反例，不把论证质量等同于个人喜恶 |
| 情绪词能直接推出作者人格 | 只描述文本中的情绪和立场线索，不做心理诊断 |
